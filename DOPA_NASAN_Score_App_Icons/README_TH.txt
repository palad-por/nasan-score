DOPA NASAN Score — App/Web Icon Pack

ไฟล์หลัก
- icon-1024.png          ต้นฉบับสำหรับ App Store / เก็บเป็น Master
- apple-touch-icon.png   สำหรับ Add to Home Screen บน iPhone/iPad
- icon-192.png           สำหรับ PWA/Android
- icon-512.png           สำหรับ PWA/Android
- icon-maskable-512.png  สำหรับ Android/PWA ที่ครอปเป็นวงกลม/สี่เหลี่ยมมุมมน
- favicon.ico            สำหรับแท็บเว็บ/เบราว์เซอร์
- favicon-16/32/48.png   favicon แบบ PNG
- icon-transparent-*.png เวอร์ชันพื้นรอบนอกโปร่งใส
- manifest.webmanifest   ตัวอย่าง manifest สำหรับ PWA
- HTML_SETUP.txt         โค้ด <link> พร้อมนำไปวางใน <head>

วิธีใช้แบบเร็ว
1) อัปโหลดโฟลเดอร์นี้ไปไว้ที่ public/icons หรือ wwwroot/icons ของเว็บ
2) คัดลอกโค้ดจาก HTML_SETUP.txt ไปไว้ใน <head>
3) ถ้าเป็น PWA ให้ใช้ manifest.webmanifest และตรวจ path /icons/... ให้ตรงกับโปรเจกต์
